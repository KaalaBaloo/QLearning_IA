# Formato de fichero de mapa:
#   Línea 1:          <filas> <columnas>
#   Líneas @xxx:      metadatos opcionales
#     @start r c
#     @goal r c
#     @pit r c prob    (prob de muerte en [0,1])
#     @coin r c bonus
#   Resto:            1 línea por fila; cada carácter representa las paredes
#                     de esa celda combinando las letras U R D L. Un '.' indica
#                     celda sin paredes propias. Las paredes exteriores son
#                     implícitas.
#
# Ejemplo: mapa 5x5 por defecto con un pozo en el centro y dos monedas.
5 5
@start 0 0
@goal 4 4
@pit 2 2 0.5
@coin 0 4 15
@coin 3 1 5
..R..
.R...
..RD.
.RR..
..U..
